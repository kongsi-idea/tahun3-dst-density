# 浮沉实验室 v2.0 规格（2026-09-16 老师确认）

> v1 问题：看起来廉价、操作顺序不逻辑、结果条用「轻/重」加深误解、一次只能放一个物体、没有记录、挑战模式形同虚设。
> v2 目标：专业科学模拟软件质感（方向 A：PhET / Labster 类），四个实验站对应 DSKP 7.1.1–7.1.4，老师投影模式 + 学生自学模式。
> 课本未取得：只按 DSKP 摘要做；**不做液体分层、不做加糖**，增加密度只用「加盐」。

## 0. 技术约束
- 纯前端，无 build、无新依赖、无后端。浏览器直接开 `index.html` 可跑（也要能被 `npx serve` 起）。
- 档案：`index.html`、`css/styles.css`、`js/data.js`（物体/题目数据）、`js/sim.js`（水槽物理与渲染）、`js/app.js`（流程、模式、记录、报告）。删除旧的根目录 `app.js`。
- 字体只从 Google Fonts：`Noto Sans SC`(400/500/700) + `IBM Plex Mono`(500，数值读数用)。
- 物体图：`assets/objects/<id>.png`（透明背景，另有 Codex 生成中）。图片载入失败时要有体面的 fallback（中性灰圆角块+名称首字），不可破图。
- **禁止 emoji 与 ▲▼ 这类字符当图标**。图标一律内联 SVG，线性、1.75px 描边、统一 20px 视框（参考 Lucide 风格，自己写 path）。
- 学校环境：Windows + Chrome、触控一体机、投影。拖拽用 Pointer Events；**每个拖拽都要有「点选 → 点水槽/按『放入水槽』」的替代操作**；hover 不承载必要功能；点击目标 ≥ 44px。
- `prefers-reduced-motion` 时去掉波纹/摆动，物体直接到平衡位置。
- localStorage 只存进度与模式偏好，读写全部 try/catch，读不到也能正常用。
- 界面语言：简体中文，马来西亚华语用法；对象是 8–9 岁学生，句子短。科学术语用：密度、浮、沉、液体、清水、盐水。

## 3. 水槽（sim.js）
- SVG 绘制玻璃烧杯型水槽：玻璃壁（双线+内高光）、侧边刻度（每 100 mL 短刻度、每 500 mL 长刻度+数字，IBM Plex Mono 11px）、水体上浅下深渐层、水面带细亮线和轻微弯月面；底部桌面细阴影。
- 盐水：水体颜色微微偏暖灰（插值到 `--salt-soft` 20%），不要撒白点花纹。
- 同时可放多个物体（上限 6，超过时提示先清空）。
- 物理（每帧 rAF，dt 上限 1/30s）：物体视为高 h 的块，浸入比例 f = 浸入高度/h。加速度 `a = g*(1 - ρ液*f/ρ物) - k*v`（在水中 k 大，空气中 k≈0），把 a 限制在 ±3g 以避免泡沫弹飞。平衡时浸入比例 = ρ物/ρ液（浮）或沉底。要求：2.5 秒内稳定、无抖动；稳定后浮体只做 ±2px、2.8s 周期的轻微浮动。
- 物体入水时：水面圆形涟漪（SVG ellipse 放大淡出 600ms）。**不要**满屏水滴、气泡装饰。
- 水位随物体浸入体积微微上升（排水，用视觉比例即可），连结 6.1 体积概念。
- 物体水平位置：取放下点 x，夹在壁内；稳定后若与邻居重叠则水平推开。
- 放入流程：拖到水槽（或点选+放入）→ 物体停在水面上方悬空 + 出现预测浮层（自学：[会浮 ↑] [会沉 ↓]；老师：「全班先预测」[揭晓]）→ 选定后才落下 → 稳定后发出 `settled` 事件（物体 id、浮/沉、预测）。
- 每个水中物体旁显示小标签（名称 + 浮/沉 icon）；「显示数据」开时加密度值。
- 加盐：勺子 SVG 从上方倾倒，盐粒落下溶解 700ms，之后液体密度 +0.02（上限 8 勺 = 1.16），所有水中物体依新密度重新运动（鸡蛋会慢慢升起，这是 ③ 站的高光时刻，不要瞬移）。
- 液体密度读数器（水槽右上角小仪表）：显示「清水」或「盐水 · N 勺」；数据开时显示 1.00–1.16 g/cm³。

## 5. 四个实验站

### ① 预测与分类（7.1.1 推断物体浮沉）
- 物体架：12 个物体。
- 步骤：(1) 至少测试 8 个物体（每个都先预测）→ (2) 分类：记录表切换成「浮 / 沉」两栏视图，自动依结果分栏 → (3) 结论题。
- 记录表栏位：物体（小图+名）｜我的预测｜结果｜对不对（SVG 勾/叉）。预测对错不扣分，猜错时的提示是「和预测不一样——这正是值得研究的地方」。
- 结论题：「会浮的物体，有什么共同点？」A 都比较轻 / B 都比较小 / C 它们的材料密度比水小 ✓。选错给针对性解释（例：苹果比铁钉重得多，却浮起来）。

### ② 是重量还是密度？（7.1.2 联系浮沉与密度）
- 实验台加一台电子天平（SVG，LCD 读数 IBM Plex Mono，读数永远显示克——质量本来就是可以称的）。物体可先放天平称再放水槽。
- 固定三组对比，任务卡逐组引导：
  1. 大木块 vs 小铁钉：先称（600 g vs 9 g），预测哪个沉 → 放入。
  2. 大木块 vs 小木块：都浮。
  3. 大石头 vs 小石头：都沉。
- 每组结束弹出一句观察：「重的不一定沉」「同一种材料，大的小的结果一样」。
- 密度示意卡（右栏）：三个同样大小的方框，内部粒子（小圆点）排列 松（木）／中（水）／紧（铁），标题「一样大小，里面挤得多紧？」，说明「挤得越紧，密度越大。密度比水小会浮，比水大会沉」。纯 SVG 图解，不是插画。
- 结论题：「一个物体会浮还是会沉，由什么决定？」A 物体有多重 / B 物体有多大 / C 物体的密度和液体的密度比较 ✓。

### ③ 改变液体（7.1.3 增加水的密度的方法）
- 进站时水槽自动放入鸡蛋（清水中沉底）。工具列：[加一勺盐] [恢复清水]。
- 记录表：盐（勺）｜鸡蛋的位置（沉在底部 / 离开底部 / 浮上水面）——每加一勺自动加一行。
- 提示「科学家的习惯：每次只改变一样东西（盐的份量），其他不变」（控制变数）。
- 目标：让鸡蛋浮起来（第 4 勺时离底，之后浮上）。达成后显示观察：「加盐让水的密度变大；当水的密度比鸡蛋大，鸡蛋就浮起来。」
- 结论题：「怎样让清水的密度变大？」A 加更多清水 / B 加盐 ✓ / C 把水倒进更大的容器。
- 可额外把其他物体放进盐水比较（不强制）。

### ④ 生活中的难题（7.1.4 应用密度知识）
四张任务卡，左栏列表切换：
1. **神秘方块**：三个没有标签的方块 X/Y/Z（SVG 画中性灰金属质感方块，标 X Y Z），密度 0.80 / 1.10 / 1.40。学生可在清水、满盐水（8 勺）里测试，然后把 X Y Z 拖（或点选）排进「密度小 → 大」三格。正确：X < Y < Z。提示：Y 在清水沉、在盐水浮。
2. **做木筏**：从 12 种材料中选 3 种做能浮的木筏。按「放下水试试」→ 所选材料一起放入水槽。全部密度 < 1 才成功；有会沉的，指出是哪一个及原因。
3. **救生衣**：「救生衣里面为什么装泡沫材料？」A 泡沫很漂亮 / B 泡沫的密度比水小很多，能帮人浮起来 ✓ / C 泡沫很重。
4. **海水和河水**：「为什么人在海水里比在河水里容易浮起来？」A 海水比较冷 / B 海水里有盐，密度比河水大 ✓ / C 海里的浪比较大。
- 每题答错给解释，可以重答；答对显示简短说明。

- Footer 一行：「课堂点子铺 · 浮沉机制概念参考 PhET Density（科罗拉多大学），界面与程序为原创实现 · v2.0」。
